# Credits and influences

No Slop Web was written by Amber Gargrish (gargrish.com) after building the Platepoint restaurant platform UI end to end, using the skills, guides and talks below. All text in this repository is original writing; no files were copied from these projects. Read the originals: each goes deeper on its own area.

## Open source agent skills

- **Hallmark** by Nutlope (MIT), github.com/Nutlope/hallmark: the idea of a hard floor against AI defaults and a dealt design direction so builds do not converge.
- **Taste Skill** by Leonxlnx (MIT), github.com/Leonxlnx/taste-skill: anti-slop frontend rules for marketing sites and a finish gate.
- **Impeccable** by Paul Bakaus (Apache 2.0), github.com/pbakaus/impeccable: audit, critique and polish playbooks.
- **UI UX Pro Max** by nextlevelbuilder, github.com/nextlevelbuilder/ui-ux-pro-max-skill: styles, palettes, font pairings and UX rules.
- **Web Interface Guidelines** by Vercel (MIT), github.com/vercel-labs/web-interface-guidelines: interface and accessibility review rules.
- **Design Motion Principles** by Kyle Zantos (MIT), github.com/kylezantos/design-motion-principles: motion through the lenses of Emil Kowalski, Jakub Krehel and Jhey Tompkins.
- **frontend-design** by Anthropic: guidance on intentional aesthetic direction.

## Design references

- **Laws of UX** by Jon Yablonski, lawsofux.com.
- **Refactoring UI** by Adam Wathan and Steve Schoger: hierarchy, spacing and color thinking.
- **Practical Typography** by Matthew Butterick: typographic details.
- **Utopia** (utopia.fyi): fluid type and space with `clamp()`.
- **WCAG 2.2** by the W3C: accessibility criteria.

## Talks and videos

- **Charles Liu**, "10 niche design hacks (part 2)": the prompt for `interaction-details.md` (double submits, hit areas, theme flash, image space, Enter to submit, scroll margin, validate on blur, error states, pausing toasts, share images).
- **Charles Liu**, "10 niche mobile hacks": the prompt for `mobile-details.md` (16px inputs, tap highlight, numeric inputmode, hover media query, OTP autofill, overscroll contain, email input type, no double-tap zoom, enter key hint, scroll snap).

- **Charles Liu**, "20 practical animation tips": prompts for the practical rules in `motion.md`.
- **@motion_ui_interface**, "More smooth details, in slow-mo" and "Icons that feel alive": prompts for `motion-details.md`.
- **designmotionhq**, "The perfect text input", "Airbnb-style search, recreated" and "Typography is a system": prompts for `forms-and-flows.md` and the type audit in `typography.md`.
